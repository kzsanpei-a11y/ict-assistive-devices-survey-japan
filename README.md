# 情報通信支援用具の給付実態調査

視覚障害者向けの情報通信支援用具について、全国の自治体がどのような品目を、どのような基準で給付しているかを、自治体の一次資料（要綱・種目表などの原文）に基づいて自治体別に調べた調査の記録です。

調査とりまとめ：星野和寿

## 調査の方法（原文主義）

- 判断の根拠は、各自治体が公開している一次資料の原文だけに置きます。まとめサイトや二次情報では判定しません。
- 従来の品目（パソコン用ソフトウェア・周辺機器など）と、最近の品目（スマートフォン・タブレット本体、支援アプリ、サブスクリプション型の利用料など）を、同じ重さで扱います。
- 支援アプリの扱い：統合品目（パソコン等）の種目表で、性能欄にアプリケーション（アプリ）の記載がある場合は、その統合品目の一部として数えます。支援アプリという単独の種目があるかどうかは、種目表にその記載がある場合に限ります。
- 判定は次の4つに明確に分けます。
  - 検証済み：種目表などの原文で、品目・基準額・耐用年数を確認できたもの
  - 条件付き：原文で確認できたが、等級・年齢・用途などの条件が付くもの
  - 未検証：今回の調査では一次資料に到達できなかったもの。**未検証は「給付がない」という意味ではありません**
  - 品目なし確認済み：種目表の全文を確認し、その品目が載っていないことを確かめたもの
- 今回確認できた分と、従前の判定を引き継いだ分は、混ぜずに区別して記録します。

## 現在の状態

- 全国1,741市町村について、調査の実行が一巡しています（2026年10月31日〜11月3日）。
- 現在は統合と再検証の段階です。再検証の結果は、照合が済むまで「完了・未検証」として扱い、確定した内容と混ぜません。
- このリポジトリの内容は、2026年11月時点の調査記録です。実際の給付の条件は変わることがあります。最新の内容は、必ず各自治体の公式情報で確認してください。

## 中身

- `調査結果/`：都道府県別の調査結果（47都道府県分。北海道は前半・後半の2ファイル、千葉県はパイロット結果が参考資料側にあります）
- `参考資料/`：調査計画案、フェーズ0（準備調査）結果、フェーズ1（千葉県パイロット）結果、根拠法令の時系列まとめ、厚生労働省の2026年資料とスマートフォン一体型給付についてのメモ

## 連携・情報共有について

類似の調査をされている方、自治体・支援団体の方との情報共有や連携を歓迎します。お気づきの点、訂正、追加の一次資料などは、このリポジトリのIssueでお知らせください。連絡先メールは tudoijp@gmail.com です。

一次資料の原文に基づく訂正提案は、出典（自治体名と資料名、可能ならURL）を添えていただけると、照合が進めやすくなります。

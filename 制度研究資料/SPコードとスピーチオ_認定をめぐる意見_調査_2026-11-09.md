# SPコードとスピーチオ 認定をめぐる意見の所在 調査

- 調査日：2026年11月9日
- 位置付け：情報通信支援用具の給付実態調査の補強調査
- 取り扱い：完了・未検証。確定版およびGitHubへは反映しない。
- 基本方針：意見が存在することと、その意見の内容が事実かどうかを分ける。価格や時期の符合だけを、不透明さの証拠とは扱わない。

## 結論の要約

1. SPコードが二次元コードの一種であることは、公的機関、メーカー関係資料、学術論文で確認できた。
2. スピーチオは、一般の活字を直接OCRで読む装置ではなく、紙面に印刷されたSPコード等の暗号化情報を読み取り、音声化する「視覚障害者用活字文書読上げ装置」である。
3. 活字文書読上げ装置という種目が平成15年（2003年）に日常生活用具の給付対象となったことは、国立障害者リハビリテーションセンター神戸センターの資料で確認できた。
4. 「急激な開発」「急激な認定」「不透明」という表現で、スピーチオの開発・認定過程そのものを直接批判した公表資料は、今回探した範囲では見つからなかった。
5. ただし、認定や普及の優先順位、実用性、価格、作成負担、当事者参加、中立的評価、開発情報の早期公開をめぐる疑問や問題提起は見つかった。最も近い記録は、京都ライトハウスの2007年コラム、全国視覚障害者情報提供施設協会の2008年研究報告書、日本視覚障害者団体連合の2018年要望である。
6. スピーチオの発売時期と価格には資料間のずれが残る。115,000円は公的冊子で確認できる。一方、2008年の調査報告書は、スピーチオとテルミーをまとめた製品欄で販売価格99,800円、販売開始を2004年4月としている。2002年は、二次資料では廣済堂による第二号機の発表と「スピーチオ」の命名の年とされる。発表、命名、発売を同一視できない。

## 1. 目的と方法

### 1.1 目的

ユーザーの指摘する、次の意見の所在を探した。

- SPコードは二次元コードの一種である。
- 製品「スピーチオ」について、その「急激な開発」と「急激な認定」の不透明さを指摘する意見がある。
- ここでいう「認定」は、日常生活用具の給付対象としての認定、具体的には平成15年（2003年）の対象化を指すとみられる。

本調査の目的は、その意見の真偽を断定することではない。公表資料のどこに、どのような意見が記録されているかを確認し、ユーザーの指摘と、資料で確認できる範囲との対応を整理することである。

### 1.2 調査方法

公開ウェブ資料を対象に、次の資料群を確認した。

- 国立障害者リハビリテーションセンターおよび同センター神戸センターの公表資料
- 厚生労働省の告示、会議資料、研究事業報告書
- 全国視覚障害者情報提供施設協会の研究報告書
- 日本視覚障害者団体連合の公式要望
- 京都ライトハウスの公式コラム
- 廣済堂関係者による研究会資料およびDINF掲載記事
- 日本視覚障がい情報普及支援協会のQ&A
- 学術論文（日本印刷学会誌）
- 業界新聞、一般メディア記事、二次資料

検索語は、「スピーチオ」「SPコード」「活字文書読上げ装置」「認定」「給付」「不透明」「批判」「疑問」「問題点」「急激」「癒着」「談合」「利権」「補助金」等を組み合わせた。

国会会議録については、一般ウェブ検索で関連記録が浮上するかを確認した。国会会議録検索システムの本文を網羅的に検索し終えたものではないため、国会関係は未確認事項として残す。

### 1.3 団体名の区別

似た名称の団体を混同しないため、本調査では次のとおり区別する。

- 全国視覚障害者情報提供施設協会（全視情協）：2008年研究報告書の作成主体。
- 日本視覚障がい情報普及支援協会（JAVIS）：SPコードの普及に関わり、後にUni-Voiceも扱った団体。
- 日本盲人会連合：当時の名称。現在の日本視覚障害者団体連合。SPコード付き印刷物の拡大を図るプロジェクトや、音声コードに関する要望に関わった。

ユーザーの委任文にあった「日視情協などが関わった」という前提は、この3団体などの役割を分けないと正確に確定できない。

## 2. SPコードの確認結果

### 2.1 基本的な仕組み

SPコードは、文字情報を内包したマトリクス型二次元シンボルである。紙に印刷されたSPコードを専用読取装置で読み取ると、格納されたテキストデータを音声で聞くことができる。

兵庫県の公式ページは、音声コードを「紙媒体に印刷された文字情報を、音声情報で伝えるための二次元コード」と説明し、その種類としてSPコードとUni-Voiceを挙げている。SPコードは専用の視覚障害者用活字文書読上げ装置で読み上げでき、装置購入には市町村の日常生活用具給付等事業による助成があるとしている。

- 兵庫県「『音声コード』の活用について」  
  https://web.pref.hyogo.lg.jp/kf10/universal/univoice.html

廣済堂関係者が執筆したDINF掲載記事は、SPコードを「18ミリメートル角に日本語で約800字を格納できるマトリクス型二次元シンボル」と説明している。専用読み取り機スピーチオに読み取らせると、格納されたテキストデータを音声で読み上げる。作成にはMicrosoft WordとSPコード作成ソフトが使われた。

- DINF「紙のユニバーサルデザインを実現するSPコードコミュニケーション『スピーチオ』」  
  https://www.dinf.ne.jp/doc/japanese/prdl/jsrd/norma/n252/n252_07-01.html

日本視覚障がい情報普及支援協会のQ&Aも、SPコードとUni-Voiceはいずれも音声コード（二次元コード）であると説明する。ただし、SPコードは従来の専用機である活字文書読上げ装置を前提にした仕様であり、スマートフォン用リーダーアプリでは読み取れないとしている。

- 日本視覚障がい情報普及支援協会「Uni-Voice Q&A」  
  https://www.javis.jp/javis-appli-form/univoice-faq

### 2.2 開発主体、特許、商標

二次資料であるWikipediaは、SPコードが2003年に株式会社オリジナルデザインと株式会社廣済堂により共同開発されたと記している。ただし、この共同開発と年次を、今回開いたメーカー公式資料や公的資料の本文では確認できなかった。そのため、本調査では一次・公的資料で確定した事実としては扱わない。

- Wikipedia「SPコード」（二次資料）  
  https://ja.wikipedia.org/wiki/SP%E3%82%B3%E3%83%BC%E3%83%89

2010年の画像電子学会研究会における廣済堂関係者の資料は、SPコードを「新しい2次元シンボル」とし、廣済堂が特許を取得したこと、SPコードとスピーチオが登録商標であることを記している。作成ソフトには、無償の「SP Code maker - one click edition」と有償の「SP Code maker pro. Ver1.1」等があった。

- 画像電子学会第28回VMA研究会、廣済堂・深見拓史「音声情報によるユニバーサルデザインの実現」  
  http://www.hi-ho.ne.jp/y-komachi/committees/vma/confs/vma28/vma28-5.pdf

国立障害者リハビリテーションセンター神戸センターの資料は、「株式会社廣済堂は音声コードのことを『SPコード』という商標名で呼んでいるようです」と記している。

- 国立障害者リハビリテーションセンター神戸センター「センターだより」  
  https://www.rehab.go.jp/kobe/txt/tayori66_05.txt

以上から、廣済堂がSPコードの特許、商標、製品化に深く関わったことは公表資料で確認できる。オリジナルデザインとの共同開発という点は、現時点では二次資料に基づく記述にとどまる。

### 2.3 「SP」の語義

WikipediaやWeblio等の二次資料には、「SP」は「スーパー」の意味であるという説明がある。しかし、今回確認したメーカー関係資料、公的機関資料、研究報告書では、その語義を確認できなかった。

したがって、「SP」が何の略称または意味であるかは、本調査では未確認とする。

### 2.4 標準化

2010年の廣済堂関係者資料では、国際標準化活動として、電子情報技術産業協会（JEITA）の標準化委員会で検討中であり、IEC TC100/TA10で新提案が承認され、ドラフト作成中だったとされている。対象は「Texture map for auditory presentation of printed texts」であった。

- 廣済堂関係者資料  
  http://www.hi-ho.ne.jp/y-komachi/committees/vma/confs/vma28/vma28-5.pdf

画像電子学会の標準化解説は、IEC 62665 Ed.1が2012年5月9日に発行されたことを記している。同規格は、印刷テキストの音声表現のためのテクスチャマップについて、符号化方式、物理的形状と寸法、印刷時の追加的特徴、復号と音声提示等を規定する。

- 画像電子学会「IEC/TC 100におけるAAL技術の標準化」  
  https://www.iieej.org/public/committees/vhis/confs/vhis2/vhis2-5rev4.html

日本印刷学会誌の論文は、IEC 62665:2015を音声コードの国際標準として参照し、印刷品質については関連規格IEC 62875:2015があるとしている。

- 深見拓史、植村八潮、野口武悟「行政機関における音声コード採用の現状と課題」『日本印刷学会誌』54巻6号  
  https://www.jstage.jst.go.jp/article/nig/54/6/54_403/_pdf

### 2.5 使われ方

公表資料では、SPコードの用途として、自治体の広報誌や通知、福祉のしおり、処方箋や薬の情報、金融機関の情報文書、選挙公報、公共料金の請求書、商品パッケージ、メニュー等が挙げられている。

DINF掲載の岡本昇氏の文章は、平成15年度から、SPコードを読み取って音声で再生する装置を重度視覚障害者が購入する際、厚生労働省の日常生活用具給付事業による助成が受けられるようになったと記している。同時に、助成対象が重度視覚障害者に限られること、弱視者や高齢者、外国人へ利用が広がるかが課題であるという見方も示している。

- DINF「新しい音声メディア『SPコード』」  
  https://www.dinf.ne.jp/doc/japanese/prdl/jsrd/norma/n264/n264_02-01.html

厚生労働省は2007年の全国厚生労働関係部局長会議資料で、SPコード作成ソフトが無償配布されていることを挙げ、行政情報の提供における積極的な活用と、市町村への周知を求めている。これは、少なくとも2007年時点では、国がSPコードの行政利用を推奨していたことを示す。

- 厚生労働省「全国厚生労働関係部局長会議資料（障害保健福祉部）」  
  https://www.mhlw.go.jp/topics/2007/bukyoku/syougai/r-chiiki.html

## 3. スピーチオの確認結果

### 3.1 機能：OCRではなく、暗号化情報の読み取り

スピーチオは、紙面の活字そのものをOCRで認識する一般的なOCR読書機ではない。同一紙面上に印刷されたSPコード等の暗号化情報を読み取り、音声化する装置である。

現行の厚生労働省告示でも、「視覚障害者用活字文書読上げ装置」は、「文字情報と同一紙面上に記載された当該文字情報を暗号化した情報を読み取り、音声信号に変換して出力する機能を有するもの」と定義されている。これは消費税関係の告示における定義であり、2003年当時の給付要綱そのものではないが、制度上の機能の性格を確認する材料になる。

- 厚生労働省告示第130号（現行テキスト）  
  https://www.mhlw.go.jp/web/t_doc?dataId=33048720

JAVISのQ&Aも、OCR機能で直接文字認識する機器と音声コードの仕組みを区別している。OCRには漢字の読み間違い、表やレイアウトによる制約がある一方、音声コードは事前に用意されたテキスト情報を読み上げる仕組みである。

- 日本視覚障がい情報普及支援協会「Uni-Voice Q&A」  
  https://www.javis.jp/javis-appli-form/univoice-faq

DINFのメーカー関係者記事によれば、スピーチオはSPコード内のテキストデータを音声で読み上げるほか、点字プリンタへ接続すれば点字出力、パソコンへ接続すればテキスト出力が可能と説明されている。

- DINF「紙のユニバーサルデザインを実現するSPコードコミュニケーション『スピーチオ』」  
  https://www.dinf.ne.jp/doc/japanese/prdl/jsrd/norma/n252/n252_07-01.html

### 3.2 開発と普及に関わった主体

日本食糧新聞の2003年12月22日記事は、スピーチオを株式会社廣済堂が開発し、NPO日本視覚障がい情報普及支援協会が普及に努めていると記している。同記事によれば、2003年12月上旬から、スピーチオに対応したピザーラのメニューカタログが全国配布されていた。少なくとも2003年末には、実際の利用場面に投入されていたことが分かる。

- 日本食糧新聞「フォーシーズ『ピザーラ』、音声メディア対応しゃべるメニュー導入」  
  https://news.nissyoku.co.jp/news/nss-9257-0027

DINFのメーカー関係者記事は、開発メンバーに視覚障害者も参加し、試作機の段階で各地のリハビリテーション施設や都道府県の視覚障害者団体等で体験してもらったと記している。また、日本盲人会連合を主幹として、企業や自治体が配布する印刷物にSPコードを添付し、情報のノーマライゼーションを目指す「バリアフリープロジェクト」を発足したとしている。

この記述はメーカー側の説明であり、開発過程全体を第三者が検証した記録ではない。ただし、公表資料の範囲では、開発初期から視覚障害当事者や団体が全く関与していなかったという単純な図式は確認できない。

### 3.3 給付対象化（2003年）

国立障害者リハビリテーションセンター神戸センターの資料は、活字文書読上げ装置が平成15年に「障害者日常生活用具」の給付対象として認定され、購入時に代金の9割を自治体が補助する仕組みだったと説明している。具体的な商品として、廣済堂のスピーチオと後継機種、日本福祉サービスのテルミーを挙げている。

- 国立障害者リハビリテーションセンター神戸センター「センターだより」  
  https://www.rehab.go.jp/kobe/txt/tayori66_05.txt

日本印刷学会誌の論文は、東京都練馬区が2003年4月に音声コード読み取り装置を「視覚障害者向け日常生活用具」として認定し、その直後から「障害者福祉のしおり」への採用を検討し、他の23区と比較して早く実施したと記している。

- 「行政機関における音声コード採用の現状と課題」  
  https://www.jstage.jst.go.jp/article/nig/54/6/54_403/_pdf

ここで区別すべきなのは、次の2層である。

1. 国の事業枠組みの中で、活字文書読上げ装置という種目が給付対象となったこと。
2. 各自治体が、自らの要綱や運用で装置や種目を位置付け、給付を行ったこと。

日常生活用具の種目や基準額は、最終的には市町村の制度設計に委ねられる部分が大きい。2003年の対象化を、特定製品そのものに対する一回の国の「認定」とだけ理解すると、制度の実態を見誤る可能性がある。

### 3.4 価格

国立障害者リハビリテーションセンターの冊子「福祉用具の紹介」は、スピーチオとテルミーが視覚障害者用活字文書読上げ装置として日常生活用具に認定されていると説明し、スピーチオの価格を115,000円（非課税）、製造元を廣済堂スピーチオ販売（株）と記載している。

- 国立障害者リハビリテーションセンター「福祉用具の紹介」  
  https://www.rehab.go.jp/TrainingCenter/japanese/TCletter/No2/11_story.html

一方、全視情協の2008年研究報告書の製品調査では、スピーチオ（廣済堂）とテルミー（日本福祉サービス）を同一の製品欄にまとめ、販売価格99,800円（非課税）、販売開始年月を「2004年4月～（廣済堂の『スピーチオ』発売）」、販売実績を約5,700台、日常生活用具の指定地域を「全国」と記録している。

- 全国視覚障害者情報提供施設協会『視覚障害者に対する新たな情報提供システムに関する研究』報告書（2008年3月31日）  
  https://www.dinf.ne.jp/doc/japanese/resource/jiritsu-report-DB/db/19/143/report.pdf

この2資料の価格と時期は一致しない。考えられる説明としては、価格改定、仕様や販売形態の違い、調査票で複数製品をまとめたこと、資料側の記載違い等があるが、今回の資料だけではどれか一つに決められない。

したがって、価格については、資料名と時点を付けて併記するのが適切である。115,000円という価格自体は公的冊子で確認できるが、それが2002年の発売当初価格であったことまでは確定できない。

| 2005年9月 | テルミーが発売された | 全視情協報告書の補足による。 |
| 2009年9月5日 | 後継機スピーチオプラスが日常生活用具の指定品目となったと販売店資料が説明 | 初代スピーチオの2003年対象化とは別の出来事として扱う。 |

二次資料の年表だけを見ると、2002年の第二号機発表から2003年の対象化までが短く見える。しかし、同じ二次資料の年表には1994年の概念、1996年の試作、2000年の受賞という前史も置かれている。したがって、2002年から2003年だけを切り取って「急激な開発」と断定することはできない。

### 3.6 スピーチオプラス

スピーチオプラスは、パソコンに接続したカメラスキャナーでSPコードを読み取り、音声やテキストへ変換する後継機である。販売店の製品ページは、販売価格49,800円、平成21年9月5日より視覚障害者用活字文書読上げ装置として重度障害者（児）日常生活用具の指定品目となり、給付金の範囲内で購入できるようになったと説明している。

- テクノマート「廣済堂 SPコード専用読取機 スピーチオプラス」  
  https://www.technomate.jp/speecho+.htm

廣済堂関係者の2010年資料も、スピーチオプラスがスピーチオの後継機として開発・販売され、厚生労働省が日常生活用具「活字文書読み上げ装置」に指定したとしている。

- 廣済堂関係者資料  
  http://www.hi-ho.ne.jp/y-komachi/committees/vma/confs/vma28/vma28-5.pdf

WikipediaのSPコード記事にある「2009年9月5日より日常生活用具の指定品目となった」という記述は、この後継機や当時の制度下での指定を指している可能性がある。2003年に活字文書読上げ装置という種目が給付対象となったことと混同しない。

## 4. 「急激な開発・急激な認定の不透明さ」を指摘する意見の所在

### 4.1 直接の表現は見つからなかった

今回の検索では、「急激な開発」「急激な認定」「不透明」という語を用いて、スピーチオの開発・認定過程そのものを直接批判した公表資料は見つからなかった。

全視情協の2008年研究報告書本文を対象に「不透明」を検索しても、該当箇所は見つからなかった。同報告書に、認定手続そのものを批判する記述も確認していない。

また、「癒着」「談合」「利権」等を含む検索でも、スピーチオの認定過程に関する具体的な記録は浮上しなかった。これは、そうした事実がなかったことの証明ではない。公開ウェブ資料の範囲では、直接の記録を確認できなかったという意味である。

以下に挙げるのは、認定の速さそのものではなく、優先順位、実用性、価格、作成負担、当事者参加、評価体制、情報公開をめぐる意見である。これらを「不透明さの証拠」とは書かない。

### 4.2 京都ライトハウス コラム「『情報』でまず必要なのはSPコード？」（2007年）

最も近い批判的意見は、社会福祉法人京都ライトハウスのコラム「『情報』でまず必要なのは SPコード？」（2007年3月1日）である。

- 京都ライトハウス「『情報』でまず必要なのは SPコード？」  
  https://www.kyoto-lighthouse.or.jp/column/20070301/

コラムの要点は次のとおりである。

1. 障害者自立支援法の見直しに伴う「視覚障害者情報支援緊急整備事業」の予算として、各自治体に急きょ100万円が付いた。視覚障害分は実質50万円程度と見ている自治体が多かった。
2. 2007年2月初め、その予算をスピーチオで知られるSPコードの普及に当ててほしいという文書が、日本視覚障がい情報普及支援協会と日盲連の連名で各自治体へ届いた。
3. SPコードは興味深い方法の一つだが、「視覚障害者にとって最も必要」かには疑問が残るとした。
4. 代替として、コードがなくても墨字を読める機器、DAISY機器、厚生労働省は認めたが市町村ではまだ少ない点字ピンディスプレイの貸出し等へ予算を使う方がよいのではないかとした。
5. DAISY機器よりも早く日常生活用具に認められたのに、なぜ普及していないのかという問いを立てた。
6. SPコード作成について、Wordで文書を作ればすぐと言われるが、きちんと音声で聞けるようにするには手間がかかる。単純な文章でも一つのマークは800字で、図や表があると相当な時間と人手・人件費がかかる。印刷方法と紙の質も限定されるとした。
7. 結論として、視覚障害者にとって本当に必要な情報機器を皆で考え、市町村へ要望していく必要があるとした。

このコラムは、「急きょ」付いた予算と、その使途としてSPコード普及が提案されたことへの疑問を示している。また、DAISY機器より早く認められたことに触れている。しかし、「急激な認定が不透明だった」とまでは述べていない。対象は主として2007年の緊急整備予算の使い方と普及の優先順位であり、2003年の認定手続そのものの検証ではない。

### 4.3 全視情協 2008年研究報告書：利用実態、座談会、評価体制への提言

全視情協の平成19年度障害者保健福祉推進事業『視覚障害者に対する新たな情報提供システムに関する研究』報告書（2008年3月31日）は、利用者調査、製品調査、座談会を含む大規模な記録である。

- 報告書本編  
  https://www.dinf.ne.jp/doc/japanese/resource/jiritsu-report-DB/db/19/143/report.pdf
- 資料編  
  https://www.naiiv.net/zensijokyo/wp-content/uploads/2022/06/sinsisu-siryou-pdf.pdf

#### 利用者調査

回答者767名のうち、SPコード朗読システムを持っていない人は613名（79.9%）、活字文書朗読システムを持っていない人は539名（70.3%）であった。

機器を持っていない理由では、「必要と思わない」が346名（45.1%）、「高価で購入困難」が205名（26.7%）等であった。自由意見には、SPコードが普及していないので使える機会が少なく汎用性がない、視覚障害者用というだけで非常に高い、という声が記録されている。

これらは普及と価格に対する利用者の評価であり、認定過程の透明性に関する意見ではない。

#### 座談会におけるスピーチオへの意見

座談会では、スピーチオについて次のような率直な意見が記録されている。

- 見た目や大きさへの戸惑いがあった。
- 郵便物の封筒にSPコードが付けば確認には使えるかもしれないが、機械はもっと小さくする必要がある。
- 100ページもある福祉の手引きの全ページにSPコードを付けてバリアフリー化した例について、目次を聞いても目的のページをすぐ開く手段がなく、ほとんど実用性がないという意見があった。
- 音声提供なら、カセットテープやDAISY CDなど他の方法も考えられるという意見があった。
- Wordで作ってそのまま読ませればよいという理解は危うく、実際には読み方を書き換え、校正し、編集したSPコードを作る作業が大変だという意見があった。
- コピーでは画質が落ちて読み取れない、レーザープリンタが必要、厚い冊子の差し込みに苦労する等の制約が挙げられた。
- 一般の人が「これが付いていればユニバーサルデザイン」と誤解する危険が指摘された。
- 授業での実証実験でも、単票や問題集のような用途には使えるが、実用性には慎重な検討が必要だったという報告があった。

#### 機器開発・評価一般への提言

同報告書は、機器開発一般について、次のような提案をしている。

- 視覚障害者ニーズをまとめる機関を設け、開発元と連携する。
- 開発段階から視覚障害者または視覚障害関係者が参画する。
- 重複開発を避けるため、公開可能な範囲で開発の目的や内容を早期に公開する。
- 機器を中立的に評価する機関を設け、評価内容や利用者の感想を公開する。
- 給付申請・購入段階で、専門家がその機器やソフトが利用者に妥当かをアセスメントする。
- 給付を受けた視覚障害者が機器をどの程度活用しているかの実態調査が行われていないため、現状は不明である。

これらは、情報公開、第三者評価、当事者参加という点で、ユーザーのいう「不透明さ」への関心と響き合う一般的な課題提起である。ただし、報告書自体はスピーチオの2003年認定を不透明だったと断定していない。

### 4.4 日本視覚障害者団体連合の音声コード要望（2018年）

日本視覚障害者団体連合の公式サイトには、「音声コードに関する都道府県及び政令指定都市への要望書提出について」が掲載されている。掲載日は2018年10月5日で、加盟団体への要請文書は同年10月3日付である。

- 日本視覚障害者団体連合「音声コードに関する都道府県及び政令指定都市への要望書提出について」  
  http://nichimou.org/all/news/secretariat-news/181005-jim/

要望書案と要請文書の要点は次のとおりである。

- SPコード、Uni-Voiceといった音声コードを刊行物や公的文書に添付するだけでは、視覚障害者全体にとって的確な情報保障とはならない。
- 音声コードを添付する場合でも、点字・録音・拡大文字など他の媒体による情報保障を併せて行うべきである。
- 音声コードを添付する場合は、必ず当事者団体の意見を聴取した上で妥当性を判断すべきである。関連機器やシステムの開発においても、当事者の意見を聴取すべきである。
- 一部の自治体等では、地域で情報提供を受ける視覚障害当事者の意見を聞かずに音声コードが一方的に導入され、他方で点字や録音、拡大文字による情報提供が縮小・廃止されるなど、各地で混乱が生じているという認識が示されている。
- 開発が当事者の声と無関係に行われたり、当事者の求めるものと異なる方向で行われたりすると、新たな困難や誤解が生じ得ることも記されている。

これは、音声コード導入過程における当事者参加と媒体選択をめぐる公式な問題提起である。ただし、対象は主として2018年当時の自治体等の導入の進め方であり、2003年のスピーチオ認定そのものを対象にした資料ではない。

### 4.5 厚生労働省研究事業：価格と申請負担への指摘

厚生労働省の障害者自立支援機器等研究開発プロジェクトの報告書は、音声コード読上げ装置の専用機について、視覚障害者にとって非常に高価であり、日常生活用具を役所へ申請すること自体に心理的負担が大きいという意見が多数寄せられたと記している。携帯電話に読み取り機能が実装されれば、利用者の負担と行政の高価な日常生活用具への費用負担を軽減できるという方向が示されている。

- 厚生労働省『文字情報を暗号化したコードを音声化できる携帯電話または携帯端末の開発に関する研究』平成21年度総括・分担研究報告書  
  https://www.mhlw.go.jp/bunya/shougaihoken/cyousajigyou/jiritsushien_project/seika/S02Report/S02_Report.pdf

別の厚生労働省研究報告書は、従来の音声コードには、読み取りに必要な余白や傾き等の制約があり、新音声コードで認識率を改善したことを技術的課題として記録している。

- 厚生労働省『文字情報を暗号化したコードを音声化できる携帯電話の開発に関する研究』平成21年度総括・分担研究報告書  
  https://www.mhlw.go.jp/bunya/shougaihoken/cyousajigyou/jiritsushien_project/seika/S05_Report.pdf

これらも、価格、負担、技術的制約に関する記録であり、認定過程の不透明さを論じた資料ではない。

### 4.6 学術論文：採用後の運用品質

日本印刷学会誌の論文は、行政機関における音声コード採用状況を調査した。現物分析では、音声コードが付いていても位置や切り込みが国際標準どおりでなく、使えない、または使いにくい印刷物があることが示された。分析対象172点のうち、すべてのページに決まった位置で音声コードがあるものは70点（40.7%）にとどまり、読み取れなかったものが2点、読み取りにくいものが約10点あった。

- 「行政機関における音声コード採用の現状と課題」  
  https://www.jstage.jst.go.jp/article/nig/54/6/54_403/_pdf

これは行政機関による採用後の運用品質の問題であり、2003年のスピーチオ認定過程に関する資料ではない。

### 4.7 一般メディアによる使い勝手への批判

Gizmodo Japanの音声コード解説記事は、SPコードの印刷条件として、レーザープリンタ600dpi以上、位置・余白・切り込み、用紙の制限等を挙げ、手軽に利用できるものではないという趣旨を述べている。また、競合するボイスアイ側の説明から、SPコードは印刷制限が多いという問題点紹介を引用している。

- Gizmodo Japan「ねんきん定期便の音声コードっていうバーコードって、なぁに？ どうやって使うの？」  
  https://www.gizmodo.jp/article/nenkin_onsei/

これはメディア記事と競合製品側の説明であり、認定過程を検証した資料ではない。使い勝手への世間の批判の一例としてのみ位置付ける。

### 4.8 見つからなかった範囲

今回の公開ウェブ調査で、次の範囲からは直接の意見記録を確認できなかった。

- 「急激な開発」「急激な認定」「不透明」という直接表現を用いた批判
- 認定過程における癒着、談合、利益誘導等を具体的に指摘する公表資料
- 全視情協2008年報告書における、スピーチオ認定手続そのものへの批判
- 厚生労働省の公開会議資料における、スピーチオ認定の速さや透明性への問題提起
- 一般ウェブ検索で浮上する範囲の国会会議録における、スピーチオを直接論じた質疑

個人ブログ等には、音声コードが読み取れない、公費が無駄に使われている、開発に補助金が投入されたといった強い批判も見られる。しかし、SPコードとUni-Voice、専用機とスマートフォンアプリの問題を混ぜて論じているものがあり、出典の信頼性も限られるため、本調査では事実認定の根拠には用いない。

## 6. 未確認事項と次に深めるべき点

### 6.1 未確認事項

1. 2003年の対象化を定めた当時の実施要綱、通知、告示等の原文の特定  
   本調査では、国立機関の解説資料で平成15年の対象化を確認したが、対象化を直接定めた当時の国文書そのものを特定するには至っていない。

   2002年の発表・命名、2003年12月の実用例、2004年4月の販売開始記録が表面上ずれている。115,000円から99,800円への価格改定があったのか、時期と理由も未確認である。

   株式会社オリジナルデザインと株式会社廣済堂が2003年に共同開発したという記述は、現時点では二次資料で確認した範囲にとどまる。

   メーカー公式資料や公的資料では確認できなかった。

5. 関係団体ごとの役割分担

   点字・視覚障害関係の機関誌、MLアーカイブ、大会の逐語記録等には、公開ウェブ検索では届かない意見が残っている可能性がある。特に2002年から2004年、2007年前後の記録が対象になる。
